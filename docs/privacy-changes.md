# GitHub Pages migration

**The GitHub wording in the privacy texts is a draft. Rudy must approve it before launch.** It is legal copy modelled on the earlier Netlify paragraphs.

Rudy should verify:

1. **The GitHub legal entity and link.** The text names "GitHub, Inc., San Francisco, USA" and links to https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement. No street address is given.
2. **The DPA and transfer basis.** The text says GitHub processes data under a data processing agreement (Art. 28 GDPR), that data may be processed in the USA, and that the transfer relies on the safeguards in GitHub's data protection agreement (EU standard contractual clauses / EU–US Data Privacy Framework).

The contact form is gone (the page shows only the email address), so the paragraph about Netlify Forms is removed. The generic contact-form section is unchanged. All other text is unchanged.

# Privacy text changes (Netlify migration)

the Netlify wording and the French additions are drafts.

1. **The Netlify legal entity and address.** The text names "Netlify, Inc., San
   Francisco, USA" and links to https://www.netlify.com/privacy/. No street
   address is given.
2. **The DPA and transfer mechanism.** The text says Netlify processes data under
   a data processing agreement (Art. 28 GDPR), that data may be processed in the
   USA, and that the transfer relies on the safeguards in Netlify's DPA (EU
   standard contractual clauses / EU–US Data Privacy Framework).
3. **The French translated additions.** The French source was truncated. Every
   section marked "NEW (translated from DE)" below was translated from the German
   text and has no French original.

   cookie / device fingerprinting / § 25 TTDSG sentence, in all three languages,
   in addition to the hosting block. It was removed as well, because the site now
   sets no cookies (see each language below).

All other text is unchanged word for word. Paragraph breaks and a few hard line
breaks were added only so the Markdown renders like the source (for example the
address block of the responsible party).
